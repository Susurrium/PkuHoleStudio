# PkuHoleStudio

PkuHoleStudio 是一款在个人电脑上运行的北大树洞客户端。它一方面覆盖树洞的大部分日常操作，让你可以直接浏览、发布和互动；另一方面增加了 24 小时热榜、最近删除、本地资料库和研究整理等能力。只有你明确保存的内容才会进入本地资料库，标签、笔记和研究项目默认留在自己的电脑上。

当前正式发布版：`v0.1.0`。前往 [最新版本下载页](https://github.com/Susurrium/PkuHoleStudio/releases/latest)，或查看 [全部变更](CHANGELOG.md)。

PkuHoleStudio 的 TUI、采集器和部分旧版兼容接口沿用并改造自 [PKUHoleTUI](https://github.com/dfshfghj/PKUHoleTUI) 的相关实现。感谢 PKUHoleTUI 作者的工作，为本项目的早期开发和兼容能力提供了重要基础。

## 功能

PkuHoleStudio 由“在线树洞”和“本地资料库”两个工作区组成。前者用于实时浏览和互动，后者用于长期保存、离线检索与个人整理，两者可以随时切换。

### 1. 支持树洞的大部分日常操作

- 浏览最新时间线和关注列表，按 PID 或关键词查找内容，查看帖子、完整评论与图片。
- 使用北大学号登录，并按提示完成短信验证码或北京大学 App 手机令牌验证。
- 发布新洞，回复或引用回复，对帖子点赞、关注和取消关注。
- 查看回复、提及等互动消息，以及树洞提供的系统通知。
- 查看课表与成绩等校园信息，无需为基本浏览和互动切换到其他客户端。

### 2. 增加热榜、归档与研究能力

- **24 小时热榜：**根据最近 24 小时内的关注和评论活跃度排序，展示 Top 10，并标明更新时间、数据来源和陈旧状态。
- **最近删除：**连接自托管 Observer 后，直接查看已确认不可访问或后来恢复的树洞；支持按 PID 打开详情，需要离线保留时再单独保存到本机。
- **本地资料库：**保存单个 PID、关注列表或最新时间线，并按需保留完整评论和图片；保存后可以离线全文搜索，并按时间、图片和本地标签筛选。
- **个人整理：**为帖子和评论添加本地标签与笔记，把相关内容整理进研究项目；这些个人信息不会写回树洞。
- **导入与迁移：**导入旧版 JSON、ZIP 或 Studio 迁移包，也可以导出可在另一台电脑恢复的迁移包或便于阅读的 Markdown 文件。
- **AI 研究：**按需连接自己选择的 AI 服务，从本地资料中检索证据、整理观点并保留引用来源；该功能默认关闭。
- **多种界面：**提供 Studio、经典树洞和 GitHub 三种 Web 界面，以及面向终端用户的键盘 TUI。

### 本地数据与安全边界

- 在线浏览的内容不会自动进入本地资料库，只有点击“保存到本地”或主动创建保存任务后才会写入。
- 保存的帖子、评论、图片、标签、笔记和研究项目默认存放在当前电脑；本地标签、笔记和项目不会上传到树洞。
- Web 服务默认只监听本机回环地址，其他设备不能直接访问；登录密码仅用于完成认证，不由网页保存，登录会话保存在本机资料目录。
- Observer 和 AI 都是可选服务。启用后，相关请求会发送到你配置的 Observer 或 AI 服务，因此应使用自己信任的服务并妥善保管访问令牌。
- 本地保存可以减少对第三方存储的依赖，但不等于绝对安全；仍应保护电脑账户，并在迁移或备份资料时妥善保管导出文件。

## 安装与使用

### Windows 安装（推荐）

PkuHoleStudio 是免安装程序，不需要另装 Go、Node.js 或数据库。

1. 打开 [最新正式版下载页](https://github.com/Susurrium/PkuHoleStudio/releases/latest)。
2. 下载 `treehole-windows-amd64.zip`，解压到一个固定且可写的目录，例如 `D:\PkuHoleStudio`。不要直接在压缩包内运行。
3. 双击“启动 PkuHoleStudio.cmd”。
4. 浏览器会自动打开；如果没有打开，请访问 `http://127.0.0.1:8080`。
5. 使用期间保持启动窗口开启，关闭窗口即可停止程序。以后仍从同一解压目录启动。

如果 Windows 提示这是未签名的应用，请先确认文件来自上面的 GitHub Release；然后在系统提示中选择继续运行。

### macOS

当前发布包适用于 Apple Silicon Mac：

```bash
tar -xzf treehole-darwin-arm64.tar.gz
chmod +x treehole-darwin-arm64
./treehole-darwin-arm64 web
```

如果 macOS 阻止首次运行，请在“系统设置 → 隐私与安全性”中确认打开。浏览器入口同样是 `http://127.0.0.1:8080`。

### Linux

当前发布包适用于使用 glibc 的 x86-64 Linux，不适用于 Alpine/musl：

```bash
tar -xzf treehole-linux-amd64.tar.gz
chmod +x treehole-linux-amd64
./treehole-linux-amd64 web
```

如果浏览器没有自动打开，请手动访问 `http://127.0.0.1:8080`。

### 第一次使用

1. 首次打开时，先选择“在线树洞”或“本地资料库”。之后可以随时切换。
2. 选择“在线树洞”后直接使用北大学号登录；程序会自动检测本机已有会话，无需手动载入。
3. 按页面提示完成短信验证码或北京大学 App 的 6 位手机令牌。密码只用于这次登录，不会由网页保存。
4. 推荐先使用“保存指定 PID”，保留默认勾选的“保存全部评论”和“下载图片到本机”。也可以保存关注列表或最新时间线。
5. 任务创建后可以离开页面；在“任务中心”查看进度。完成后切换到“本地资料库”即可搜索和整理。

如果你已经有旧资料，不需要先登录：打开“导入与导出”，选择文件，等待检查完成后再确认导入。

### 日常使用

- 想实时浏览、发洞或互动：切换到“在线树洞”。
- 想离线搜索和整理：切换到“本地资料库”，使用“全部资料”“研究项目”和帖子详情中的标签、笔记功能。
- 想保存看到的某个洞：在在线详情页点“保存到本地”；需要批量保存时，前往“登录与保存”。
- 已保存的洞会在打开详情时自动获取线上更新；需要完整读取评论时，点击“完整更新本地内容”。离线或刷新失败时仍可阅读已有资料。
- 想持续跟进关注洞：在详情页启用“持续更新此洞”，或前往“登录与保存 → 持续更新关注洞”。最多 20 个，周期可选 30、60、120 分钟，默认 60 分钟；仅在程序运行期间更新。详见[内容更新说明](docs/post-updates.md)。
- 图片没有保存完整：前往“登录与保存”，运行“补全缺失图片”。
- 想导入已有资料：打开“导入与导出 → 导入文件”，选择 JSON、ZIP 或 `.treehole.zip`，点“检查文件”，确认内容后再点“确认导入”。
- 想迁移到另一台电脑：打开“导入与导出 → 导出资料”，留空 PID 代表全部资料，点击“创建 Studio 迁移包”；任务完成后下载，再在另一台电脑导入。
- 想得到便于阅读的文件：在同一导出页面选择“导出为 Markdown”。
- 想使用 AI：前往“设置 → AI 服务”添加服务，再在“AI 使用方式”中启用，之后打开“AI 研究”。AI 默认关闭。
- 想使用删除记录和自建热榜：先部署 Observer，再按 [Observer 使用说明](docs/self-hosted-observer.md) 连接。

### 数据位置与升级

按上面的默认方式启动时：

- `data/` 保存设置、登录状态、日志、图片和导出文件。
- `treehole.db` 保存帖子、评论、标签、笔记、项目和 AI 记录。

升级时先停止程序，下载并解压新版，只替换可执行文件；保留原来的 `data/` 和 `treehole.db*`。如果要迁移全部本机状态，停止程序后复制这两部分即可。

需要把所有资料固定到其他位置时，请以后始终使用同一条命令：

```powershell
.\treehole-windows-amd64.exe --data-dir D:\PkuHoleStudio\data --db-path D:\PkuHoleStudio\data\treehole.db web
```

### 常见问题

- 双击主程序或“启动 PkuHoleStudio.cmd”会打开浏览器界面；需要终端界面时使用 `treehole-windows-amd64.exe tui`。
- 浏览器没有打开：手动访问 `http://127.0.0.1:8080`。
- 提示 8080 端口被占用：运行 `.\treehole-windows-amd64.exe web --port 8081`，然后访问 `http://127.0.0.1:8081`。
- 突然看不到原来的资料或登录状态：通常是从不同目录启动，或改变了 `--data-dir` / `--db-path`。回到原目录并使用原命令。
- 本地搜索结果异常：停止 Web 后运行 `.\treehole-windows-amd64.exe rebuild-search-index`，完成后重新启动 Web。

源码构建、命令行采集、API、目录结构、测试和安全边界见 [技术参考](docs/technical-reference.md)。
