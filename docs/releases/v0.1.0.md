# PkuHoleStudio v0.1.0

v0.1.0 是 PkuHoleStudio 的首个正式发布版。本版重点完善在线登录、24 小时热榜、Observer 最近删除和 Windows 新手流程，同时保留本地优先的数据管理方式。

## 主要更新

- 选择“在线树洞”后会优先进入北大学号登录；学号登录始终显示在主要位置，重新读取其他客户端会话收纳为次要选项。
- 热榜统一统计最近 24 小时，根据关注和评论活跃度排序，并显示更新时间、数据来源和陈旧状态。
- “最近删除”改为直接读取自托管 Observer，不再要求先把全部删除快照同步到 Studio。可以按 PID 查看详情，并只把需要离线保留的单条记录保存到本机。
- Observer 暂时不可用时，Studio 会回退到已经保存的本机缓存；完整的后台本地镜像改为默认关闭的高级选项。
- Windows 压缩包增加“启动 PkuHoleStudio.cmd”和“使用说明.txt”。普通用户解压后双击即可启动，不需要打开终端或执行哈希校验。
- 主程序无参数运行时默认打开 Web 界面；需要键盘 TUI 时使用 `treehole tui`。
- README 重新按树洞原有操作、Studio 扩展能力和本地数据安全边界组织，明确 Observer 与 AI 均为可选服务。
- 升级 React Router 及相关构建依赖的安全补丁版本；发布前依赖审计无已知漏洞。

## Windows 安装

1. 下载 `treehole-windows-amd64.zip` 并完整解压到固定目录，例如 `D:\PkuHoleStudio`。
2. 双击“启动 PkuHoleStudio.cmd”。
3. 浏览器会自动打开；若没有打开，请访问 `http://127.0.0.1:8080`。
4. 使用期间保持启动窗口开启，关闭窗口即可停止程序。

`SHA256SUMS.txt` 继续提供给需要校验下载完整性的高级用户，但不是普通安装流程的必需步骤。

## macOS 与 Linux

解压对应平台的压缩包、赋予程序执行权限，然后运行 `./treehole-<平台>-<架构>`。无参数启动会打开本机 Web 界面。

## 升级说明

- 现有帖子、评论、图片、标签、笔记、研究项目和登录会话保持兼容。
- 已有 Observer 地址和访问令牌不需要重新填写。
- Observer 的完整本地镜像现在默认关闭；日常查看热榜和最近删除不依赖镜像。需要完整离线副本时，可在设置的高级选项中重新开启。
- 在线浏览仍不会自动保存内容；只有点击“保存到本地”或创建保存任务后，内容才会进入本地资料库。

## 安全说明

Studio Web 默认只监听本机回环地址。登录密码仅用于完成认证，不由网页保存；帖子、评论、标签、笔记和研究项目默认保存在当前电脑。Observer 和 AI 是可选外部服务，启用前请确认服务由自己控制或值得信任。
