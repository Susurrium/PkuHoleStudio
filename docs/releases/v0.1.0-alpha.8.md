# PkuHoleStudio v0.1.0-alpha.8

alpha.8 是一次面向日常使用体验的小版本更新。它不增加新的产品子系统，
重点修正帖子指标与洞主身份显示，重新整理近期热榜和常用操作页面，并收掉
几个已有但容易误导用户的边缘行为。

## 本版重点

### 帖子指标与热榜

- 帖子列表、详情和三套 Web 界面分别显示评论、关注和点赞，不再把关注数与点赞数互相替代。
- 近期热榜使用居中的 Top 10 页面，并在榜单旁直接说明近 12 小时热度的计算方式。
- 热榜分别显示热度、关注和评论；Observer 与在线降级结果使用一致的字段语义。
- 洞主回复不再重复显示两个“洞主”，并通过轻量边线、底色和作者名强调与普通评论区分。

### 更直接的使用流程

- 首次进入本地资料库时，主入口改为“登录并保存内容”，已有迁移文件仍可从次入口导入。
- 设置、登录与保存、导入导出、任务和删除记录页面按常用操作重新排序。
- 版本、路径、原始错误和运行字段等维护信息收进可展开的“技术详情”，默认界面只保留用户需要的说明。
- 导入导出统一使用“迁移包”表述，不再把它描述成完整备份系统。

### 小型可靠性修复

- “补全评论”会逐页取得全部评论，不再在单洞超过 100 条时静默截断。
- 删除没有实际保存断点的 `crawler --resume`；需要从指定页继续时使用 `--start-page`。
- `treehole web` 只允许监听 `localhost` 或回环 IP，避免误把本地资料与操作接口暴露到局域网；远程 API 仍使用带 Bearer Token 的 `treehole server --allow-remote`。

## Windows 安装

1. 下载 `treehole-windows-amd64.zip` 与 `SHA256SUMS.txt`。
2. 使用 PowerShell 校验压缩包：

   ```powershell
   (Get-FileHash .\treehole-windows-amd64.zip -Algorithm SHA256).Hash
   Get-Content .\SHA256SUMS.txt
   ```

3. 解压后启动 Web：

   ```powershell
   .\treehole-windows-amd64.exe web
   ```

浏览器默认打开 `http://127.0.0.1:8080`。

## 升级说明

- 本版不增加数据库迁移，现有帖子、评论、标签、项目、笔记和 AI 记录保持兼容。
- 如果旧脚本使用了无效的 `crawler --resume`，请改为明确传入 `--start-page N`。
- 如果旧脚本让 `treehole web` 监听非回环地址，升级后会拒绝启动；需要远程 API 时请改用受 Token 保护的 `treehole server --allow-remote`。

## 已知限制

- 无 Observer 时，近期热榜根据最近 12 小时在线时间线近似计算，数据范围取决于远端当前可返回的内容。
- `crawler` 与旧版图片补全仍属于兼容工具；日常保存指定 PID 和补全缺失媒体建议使用 Web 的现代任务入口。
- 本仓库未另行声明通用开源许可证；当前使用与分发边界见根目录 `NOTICE.md`。
