# PkuHoleStudio v0.1.0-alpha.7

alpha.7 是一次面向安全收口与实际操作效率的预览版本。它建立在
alpha.6 的双工作区、Observer、Archive Contract 2.1、研究项目和证据化
AI 能力之上，不增加新的产品子系统，重点改善热点浏览、移动端本地整理、
登录传输、项目与 AI 的边界、归档结果可信度和后台任务流程。

> 本版仍是 alpha 预览版。升级前如有需要可复制资料目录与数据库。维护者
> 已取得上游权利人对本项目使用和修改历史代码的许可；本仓库未另行声明
> 通用开源许可证，具体边界见根目录 `NOTICE.md`。

## 本版重点

### Top 10 热榜

- `/api/v1/posts/hot` 支持 `limit=1..20`，省略参数时继续返回五条，保持旧客户端兼容。
- Web 请求十条结果，默认只展示前五条，用户可展开第六至第十条。
- 从导航或移动快捷入口打开“近期热榜”时自动展开完整 Top 10。
- GitHub 风格的本地概览保持六条紧凑摘要，并链接到完整榜单。
- TUI 继续展示五条，避免热榜占用过多终端高度。

### Web 操作效率

- Studio 固定侧栏从 768px 延后到 1024px；平板竖屏改用顶部工作区开关和底部导航。
- 本地帖子详情在窄屏下把项目、标签和整洞笔记放到评论之前，长评论区不再遮蔽整理入口。
- 研究项目可以直接把当前项目的 PID 范围交给导出页，最多 2000 个帖子。
- 系统导航将“保存到本地”改为“登录与保存”，覆盖首次登录、载入 TUI 会话和同步范围选择。
- Studio 侧栏不再直接陈列两种外观切换按钮，统一通过“界面与工作区设置”管理。
- Toolkit 下载和官方树洞入口集中在可选 Toolkit 传输页，普通文件导入与本地导出的主路径更清晰。

### 服务暴露与隐私

- `treehole server` 默认从 `0.0.0.0` 改为 `127.0.0.1`。
- 监听非回环地址必须显式传入 `--allow-remote`。
- 远程模式必须通过 `PKUHOLE_SERVER_API_TOKEN` 或 `--api-token` 配置至少 24 字符的令牌；所有请求都需要 `Authorization: Bearer <token>`。
- API 文档中的可识别成绩与学籍样例已替换为完全虚构数据。
- `NOTICE.md` 记录了 alpha.7 发布时的上游基线与授权边界；2026-08-09 后续取得的项目使用、修改许可见当前 `NOTICE.md`。

### 登录修复

- IAAA 登录会区分短信验证码和北京大学 App 手机令牌。
- OTP 场景明确提示从“北京大学”App 的手机令牌页面获取六位动态口令，不再提示等待短信。
- 树洞 SSO 首跳使用 HTTPS，客户端恢复系统 CA 校验；重定向令牌按结构化查询参数读取。

### 简化研究与后台流程

- 研究项目单次交给 AI 的范围统一为最近加入的 100 个 PID；超限输入、重复提交和会话详情未就绪都会在发送前拦截。
- 退役会长期占用任务队列的本地持续监控，连续采集统一交给 Observer；旧监控任务可直接取消。
- 归档导入不再承诺暂停后恢复；中断后重新上传即可，过期暂存文件会自动清理。
- 指定 PID 导出会报告请求、找到和缺失数量；Archive v2 manifest 与 Markdown 索引都会保留部分匹配信息。

## Windows 安装

1. 下载 Windows 压缩包和 `SHA256SUMS.txt`。
2. 使用 PowerShell 核对 SHA-256：

   ```powershell
   (Get-FileHash .\treehole-windows-amd64.zip -Algorithm SHA256).Hash
   Get-Content .\SHA256SUMS.txt
   ```

3. 解压到独立目录并启动：

   ```powershell
   .\treehole-windows-amd64.exe web
   ```

4. 浏览器默认打开 `http://127.0.0.1:8080`。

如确需从局域网访问兼容 API：

```powershell
$env:PKUHOLE_SERVER_API_TOKEN = '请替换为至少24字符的随机值'
.\treehole-windows-amd64.exe server --host 0.0.0.0 --allow-remote
```

客户端请求必须携带相同令牌：

```powershell
Invoke-RestMethod http://127.0.0.1:8081/health -Headers @{
  Authorization = "Bearer $env:PKUHOLE_SERVER_API_TOKEN"
}
```

不需要远程访问时不要设置 `--allow-remote`。

## 升级说明

- 退出正在运行的 TUI/Web；如需保留现有本地资料，复制资料目录和 SQLite 数据库即可。
- alpha.7 不增加数据库迁移。
- 现有 TUI 热榜、归档文件、项目、标签、笔记和 AI 研究记录保持兼容。
- 正在运行的旧持续监控升级后不能继续；归档导入中断后请重新上传。
- 不要提交或共享 `cookies.json`、数据库、真实归档、API/Observer Token、密码、验证码或真实校园数据。

## 验证范围

本版沿用现有发布门槛，不扩建测试体系。发布前验证包括：

- 前端单元测试与生产构建通过；
- Windows Chromium 主流程与经典/GitHub 视觉、响应式和键盘基线 `19/19` 通过；
- 相关 Go 包测试与 Windows SQLite FTS5 构建通过；完整测试和跨平台产物由发布工作流再次执行；
- 默认回环监听、远程模式拒绝缺少开关或 Token 的启动请求通过；
- 实测 Web 请求 `limit=10`，移动端完整展开十条且无横向溢出；
- 768px 平板使用移动导航且无横向溢出；移动详情的本地整理入口位于评论之前。

## 已知限制

- 本仓库各分支和标签已经重写，旧 `doc/api.md` 不再出现在可达历史中；GitHub 缓存、Pull Request 引用、外部克隆、Fork 和原上游仓库仍可能保留旧对象，需要分别联系 GitHub Support、协作者和上游维护者继续清理。
- 上游 PKUHoleTUI 没有声明通用开源许可证；维护者取得的项目使用和修改许可不等同于向所有下游用户授予开源许可证，具体边界见 `NOTICE.md`。
- 热榜第六至第十条使用与前五条相同的 Observer 或近似排序来源；当降级为在线时间线近似榜时，较低名次的相关性可能更弱。
- `npm audit` 会针对 React Router 7.18.1 报告两个高危包记录；对应公告明确只影响不稳定 RSC API，而 Studio 是纯浏览器 SPA、未使用 RSC。当前没有无破坏性的 v7 修复版本，依赖仍应继续跟踪并单独评估升级到 v8.3 或更高版本。
