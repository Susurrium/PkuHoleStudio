# PkuHoleStudio v0.1.0-alpha.9

alpha.9 是一次小型兼容性与可靠性更新，重点解决旧版图片、缩略图工具在使用
自定义 `--data-dir` 时仍写入其他目录，以及真实下载失败被当作“跳过”或“完成”
的问题。日常 Web 流程保持简单，数据库结构和现有本地资料均无需迁移。

## 本版重点

### 图片目录保持一致

- `crawler --fetch-images`、`crawler fetch-images` 和 `crawler fetch-thumbnails` 统一写入当前 `--data-dir` 下的 `images/` 或 `thumbnails/`。
- TUI 查找和按需下载图片也使用同一资料目录，不再依赖进程启动目录或编译时源码路径。
- TUI 在批量或按页下载新图片后刷新路径缓存，无需重启即可看到新文件。

### 下载结果可信

- 旧版图片工具现在分别报告“新下载”“已存在”和“失败”。目录创建、网络、HTTP、非图片响应和写盘错误都会作为真实失败返回。
- 专门的图片与缩略图任务会保存结果检查点；发生失败时不再显示为已完成，成功重试也不会残留上一次的失败统计。
- 按页采集中的附带图片仍是尽力而为：帖子和评论一旦成功写入，不会因为单张图片失败而重复整页；图片失败数量会出现在 CLI、TUI 或任务检查点中。

### 更简单的 Web 入口

- Web“登录与保存”继续只提供日常应使用的“补全缺失图片”，它会维护正式媒体记录及失败状态。
- 旧版图片和缩略图缓存能力继续由 CLI/TUI 保留，原命令入口和历史任务记录仍可使用。
- README 现在只讲用户能做什么、完整安装和实际使用流程；构建、命令行、API 与架构信息移入独立技术参考。代码来源说明缩减为一句 PKUHoleTUI 致谢。

## Windows 安装

1. 下载 `treehole-windows-amd64.zip` 与 `SHA256SUMS.txt`。
2. 使用 PowerShell 校验压缩包：

   ```powershell
   (Get-FileHash .\treehole-windows-amd64.zip -Algorithm SHA256).Hash
   Get-Content .\SHA256SUMS.txt
   ```

3. 解压后启动 Web：

   ```powershell
   .\treehole-windows-amd64.exe web
   ```

浏览器默认打开 `http://127.0.0.1:8080`。

## 升级说明

- 本版不增加数据库迁移，现有帖子、评论、标签、项目、笔记和 AI 记录保持兼容。
- 过去因旧工具忽略 `--data-dir` 而写入其他目录的图片缓存不会自动搬迁；这些缓存可重新下载，不需要增加迁移流程。
- 如果脚本解析旧命令的 `skipped` 文本输出，请改为读取 `existing` 和 `failed`。

## 验证范围

- 自定义资料目录、已存在文件、HTTP 失败和 TUI 路径缓存均有聚焦回归测试。
- 前端单元测试 `79/79` 通过，TypeScript 检查与生产构建通过。
- 受影响 Go 包测试、`go vet -tags sqlite_fts5 ./...` 和 SQLite FTS5 构建通过。
- 标签发布工作流会再次执行全量前端测试、Go 测试、Windows E2E，并构建 Linux、macOS 与 Windows 产物及 SHA-256 校验文件。

## 已知限制

- `crawler` 图片与缩略图命令属于旧缓存兼容工具；日常保存指定 PID 和补全缺失媒体建议使用 Web 的现代任务入口。
- 按页采集不会因附带图片失败而回滚已保存的正文；需要重试图片时可单独运行补全命令。
