# PkuHoleStudio v0.1.1

本版增加已保存树洞的自动刷新、完整更新与关注洞持续更新，三个 Web 界面使用共同的操作流程。

## 主要更新

- 打开已保存树洞时先显示本地内容，登录有效时后台获取最新正文、统计和新增评论。
- 详情页提供“完整更新本地内容”，支持重新读取全部评论，并按原保存选项补全图片；列表支持批量保存或更新。
- 可选择持续更新已经保存且仍在关注的树洞，每账号最多 20 个，周期可选 30、60、120 分钟，默认 60 分钟。
- 后台每轮最多 100 次线上请求，支持分页续传、账号隔离及调度恢复；请求统一串行执行，并遵守请求间隔和限流退避。
- 更新完成后刷新相关详情、列表和统计；经典界面重新处理评论分页，图片保存失败时准确显示部分完成。
- 离线或刷新失败时保留已有内容，标签、笔记、研究项目和历史资料继续保留。

## 安装与升级

Windows 用户下载 `treehole-windows-amd64.zip`，完整解压后双击“启动 PkuHoleStudio.cmd”。macOS 和 Linux 用户下载对应平台的压缩包，解压并运行其中的程序。

升级已有目录前先停止程序并备份资料，然后替换可执行文件，保留原有 `data/`、`treehole.db` 及其配套文件。数据库结构自动迁移。

持续更新在程序运行期间执行，关闭浏览器后仍可继续；退出程序或关闭电脑后停止。详细说明见[内容更新说明](https://github.com/Susurrium/PkuHoleStudio/blob/main/docs/post-updates.md)。
